# ICCC2025
Point Cloud Subjective Quality Assessment Dataset
This repository contains a dataset for subjective quality assessment of 3D point clouds. It includes subjective quality scores for both Poisson-reconstructed meshes and their corresponding original point clouds, along with calculated AQP and GQP.

## Dataset Description
The dataset is structured in an Excel spreadsheet (.xlsx) and contains the following sheets/columns:
Poisson Reconstruction Scores: Subjective quality evaluation scores for point clouds that have been processed using Poisson surface reconstruction.

Original Point Cloud Scores: Subjective quality evaluation scores for the corresponding original point clouds.
AQP: Atrribute Quality Parameter.
GQP: Geometry  Quality Parameter.

This data is intended for research in point cloud processing, quality assessment, and computer graphics.
